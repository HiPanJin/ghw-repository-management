# Mergington High School Security Policy

This repository is a GitHub Skills training copy of a fictional school application. Do not use it to store real student information or deploy it as a production school system.

## Supported version

Security reports should reference the current `main` branch and include the affected commit when possible.

## Reporting a vulnerability

1. Do not publish vulnerability details in a public issue or pull request.
2. Open this repository's **Security and quality** tab and select **Report a vulnerability**.
3. Use the private reporting form to describe the issue, reproduction steps, impact, affected commit, and any proposed mitigation.
4. Use fictional data in examples and omit passwords, credentials, or personal information.

The maintainer can use a private security advisory and temporary private fork to investigate and prepare a fix before public disclosure. Coordinate disclosure through that private report.

## Response process

The maintainer will review reports as availability permits, assess the impact, and discuss next steps in the private advisory. This training repository has no guaranteed response time or production support commitment.

## Thank you

Responsible disclosure helps maintainers understand and fix security problems without putting users or their data at unnecessary risk.
